Case study

Embedding context
where work happens

Property managers rely on both the Multi-Calendar and the Inbox to drive bookings, but from entirely different operational angles: one for high-level portfolio operations, the other for direct guest communication

My goal was to bring complete reservation management into both tools without disrupting their primary task, enabling instant rate adjustments in the calendar and real-time inquiry resolution in the inbox, zero tab switching required

Solution

Two layouts;
one integrated sidebar

To support both workflows without context switching, I designed a single, context-aware reservation sidebar embedded across both tools. This compact version of the main reservation page delivered consistent data and core actions for instant booking edits

Unified inbox full
context messaging

Every chat thread was anchored with the contextual reservation sidebar. Bringing reservation details, listing data, guest status, automated messaging, and retrievable quick links directly into view enabled users to edit bookings and resolve inquiries in real time

Multi calendar gridwith on-demand context

In the Multi Calendar, the sidebar triggered dynamically only when selecting a booking from the grid. Tailored for calendar management, it surfaced essential rates, occupancy metrics, and listing actions, allowing instant edits while keeping the grid view clean

Results

Zero context switching

Standardized the reservation sidebar across core tools, eliminating friction and cognitive load

Operational efficiency

Improved response times in the Inbox and increased scheduling accuracy across the Multi-Calendar grid

Scalable architecture

Built a unified UX pattern that streamlined overall user onboarding across the core product suite
